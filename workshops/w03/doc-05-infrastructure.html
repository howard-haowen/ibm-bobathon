第二章：IS EXTERNAL 計數陣列共用機制

技術背景 原始 IBM z/OS 使用 CICS Named Counter Service（NCS）維護 27 個計數器（GENACUSTNUM + GENACNT100 ~ GENACNTI99）。
ACUCOBOL-GT 轉置後改為 IS EXTERNAL 計數陣列（手冊 p.90），由 LGSETUP 初始化，各執行緒透過 IS EXTERNAL 共用同一記憶體區塊。

GENA-COUNTERS 結構

01 GENA-COUNTERS IS EXTERNAL.
   03 GENA-CUSTNUM    PIC S9(9) COMP  -- 客戶流水號計數器（LGACDB01 使用）
   03 GENA-CNT        PIC S9(9) COMP
      OCCURS 26 TIMES                  -- 各操作成功/失敗計數器（索引 1-26）

計數器索引對照（部分已確認）

索引原 CICS NCS 名稱業務含義
CUSTNUMGENACUSTNUM客戶流水號（LGACDB01 遞增）
CNT(1)GENACNT100查詢客戶成功
CNT(2)GENACNT199查詢客戶失敗
CNT(3)～CNT(26)TBDTBD（完整對照表待確認）

第三章：LGSETUP — 環境初始化

項目內容
Program-IDLGSETUP
功能初始化客戶流水號計數器、26 個操作計數器、建立日誌檔
執行方式acurun LGSETUP（命令列，無 CICS 環境需求）
結束方式STOP RUN（初始化完成後終止，不用 GOBACK）

程式流程

  1. ACCEPT WS-RECV-DATA FROM ENVIRONMENT 'GENAPP_INITIAL_CUSTNUM'
  2. 初始化 IS EXTERNAL：GENA-CUSTNUM = 初始值
  3. 清零 26 個 GENA-CNT(i)（原為 EXEC CICS Delete/Define Counter）
  4. 建立/覆蓋日誌檔（LINE SEQUENTIAL，GENAPP_LOG_FILE 指定）
  5. 寫入初始化完成訊息（原為 EXEC CICS SEND TEXT）
  6. STOP RUN

日誌檔設計

項目內容
邏輯名稱GENAPP-LOG
實體路徑環境變數 GENAPP_LOG_FILE
組織LINE SEQUENTIAL（跨平台相容文字模式）
記錄格式PIC X(80)
存取模式OUTPUT（初始化時覆蓋建立）

IBM 原始 vs ACUCOBOL 轉置對照

IBM 原始指令ACUCOBOL-GT 替代
EXEC CICS RECEIVE INTO（取得初始客戶號）ACCEPT FROM ENVIRONMENT 'GENAPP_INITIAL_CUSTNUM'
EXEC CICS DeleteQ TS（清除日誌 Queue）跳過（重開日誌檔等效）
EXEC CICS WriteQ TS（STSQ-NAME）LINE SEQUENTIAL WRITE
EXEC CICS Delete/Define Counter（26 組）IS EXTERNAL 計數陣列清零
EXEC CICS SEND TEXTDISPLAY
EXEC CICS RETURNSTOP RUN

第五章：LGWEBST5 — 統計輸出背景服務

項目內容
Program-IDLGWEBST5
功能每 60 秒從 IS EXTERNAL 讀取統計資料並輸出
執行方式獨立背景行程（PROCEDURE DIVISION 無 USING）
終止方式設定 GENAPP_STOP_LGWEBST5 = 'STOP' 觸發優雅停止
C$SLEEP 永久迴圈設計（客戶確認決策） 原始 IBM CICS：EXEC CICS Start Transid('SSST') After Minutes(1)
ACUCOBOL-GT 替代：C$SLEEP 60 永久迴圈，每 60 秒執行一次統計輸出。
C$SLEEP 為 ACUCOBOL-GT 系統程式庫函式（接收秒數），等效於原始 After Minutes(1) 語義。
此設計為客戶確認決策，保留於程式注解中。

優雅停止機制

環境變數值效果
GENAPP_STOP_LGWEBST5'STOP'下次迴圈開始時正常 GOBACK 退出
GENAPP_STOP_LGWEBST5其他或未設定繼續執行永久迴圈

第六章：LGSTSQ — 錯誤訊息日誌服務

項目內容
Program-IDLGSTSQ
功能接收錯誤訊息並寫入日誌檔（取代 CICS TDQ/TSQ 輸出）
呼叫介面CALL 'LGSTSQ' USING BY REFERENCE LOG-MESSAGE（PIC X(90)）
日誌檔路徑環境變數 GENAPP_LOG_FILE（預設 genapp.log）

程式流程

  1. ACCEPT WS-SYSID FROM ENVIRONMENT 'GENAPP_SYSID'（預設 'SYS1'）
  2. ACCEPT WS-INVOKEPROG FROM ENVIRONMENT 'GENAPP_INVOKING_PROG'（預設 'UNKNOWN'）
  3. ACCEPT WS-LOG-PATH FROM ENVIRONMENT 'GENAPP_LOG_FILE'（預設 'genapp.log'）
  4. ACCEPT WS-DATE-8 FROM CENTURY-DATE（YYYYMMDD）
  5. ACCEPT WS-TIME-8 FROM TIME（HHMMSSss）
  6. 組裝日誌記錄：[日期][時間][程式名][訊息]
  7. OPEN EXTEND LOG-FILE（附加模式，若失敗則 OPEN OUTPUT 新建）
  8. WRITE LOG-RECORD
  9. CLOSE LOG-FILE
  10. 若非程式呼叫（INVOKEPROG=SPACES）：DISPLAY WINDOW ERASE
  11. GOBACK

日誌記錄格式（109 bytes）

[YYYYMMDD] [HHMMSSss] [PROG    ] [訊息內容（90 bytes）             ]
欄位PIC說明
WS-LE-DATEX(8)日期（YYYYMMDD）
WS-LE-TIMEX(8)時間（HHMMSSss）
WS-LE-PROGX(8)呼叫程式名稱（GENAPP_INVOKING_PROG）
WS-LE-MSGX(90)訊息內容（COMMA-DATA）

呼叫此程式的完整清單

第七章：IS EXTERNAL 三程式共用資料流

系統啟動
    LGSETUP
        GENA-CUSTNUM = GENAPP_INITIAL_CUSTNUM
        GENA-CNT(1-26) = 0
        建立 GENAPP-LOG 日誌檔

交易處理（每次業務操作）
    業務程式 → 發生錯誤 → CALL LGSTSQ（寫入 genapp.log）
    LGASTAT1 → ACCEPT 交易碼/返回碼 → GENA-CNT(i) += 1

背景監控（每 60 秒）
    LGWEBST5 → 讀取 GENA-CUSTNUM, GENA-CNT(1-26) → 輸出統計

新增客戶時
    LGACDB01 → GENA-CUSTNUM += 1 → 以新流水號作為 CA-CUSTOMER-NUM

第八章：運維注意事項

⚠ 啟動順序關鍵 LGSETUP 必須在任何業務程式前執行，否則 IS EXTERNAL 計數陣列未初始化，LGACDB01 無法取得正確客戶流水號（初始值 = 0 視為未初始化）。

常見問題排查

問題現象可能原因解決方式

日誌無輸出GENAPP_LOG_FILE 路徑不存在確認目錄存在且有寫入權限
