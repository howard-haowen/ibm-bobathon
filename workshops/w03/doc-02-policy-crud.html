第三章：新增保單（ADD Policy）

LGAPOL01 — 業務邏輯層

項目內容
Program-IDLGAPOL01
功能新增保單業務邏輯層；驗證 COMMAREA、套用業務規則（可選）、呼叫 DB2 新增層
進入點MAINLINE SECTION
退出點GOBACK（正常）/ STOP RUN（ABEND）
使用 CopybookLGCMAREA.cpy（LINKAGE SECTION）

程式流程

  1. 初始化 WS-HEADER（WS-EYECATCHER = 'LGAPOL01------WS'）
  2. ACCEPT WS-TRANSID FROM ENVIRONMENT 'GENAPP_TRANSID'
  3. 驗證 DFHCOMMAREA 不為 SPACES（否則 STOP RUN）
  4. 設定 CA-RETURN-CODE = '00'
  5. 驗證 LENGTH OF DFHCOMMAREA < WS-CA-HEADER-LEN（28） → 返回碼 98
  6. 若 IN-RULES-MODE = 'Y' 且 CA-REQUEST-ID = '01AEND' → CALL 'LGAPBR01'（ODM，TBD）
  7. CALL 'LGAPDB01' USING BY REFERENCE DFHCOMMAREA RETURNING WS-DB-RETURN-CODE
  8. 若 CA-RETURN-CODE > 0 → GOBACK
  9. 正常結束：GOBACK

關鍵資料結構

名稱型態說明
WS-CA-HEADER-LENLevel 78 VALUE 28COMMAREA 最小長度編譯期常數
BUSINESS-RULESPIC XODM 模式旗標（'N'=標準, 'Y'=業務規則）
IN-STANDARD-MODE88-level VALUE 'N'預設啟用
IN-RULES-MODE88-level VALUE 'Y'需手動設定
WS-DB-RETURN-CODEPIC 9(2)子程式回傳碼
WS-VARY-FIELD49/49 VARCHARENDOWMENT PADDINGDATA 長度暫存

錯誤處理

返回碼條件處理方式
98COMMAREA 長度不足MOVE '98' TO CA-RETURN-CODE; GOBACK
ABENDDFHCOMMAREA 為 SPACESDISPLAY UPON SYSERR; STOP RUN

第七章：WRITE-ERROR-MESSAGE 共用段落

所有保單程式均包含此段落，呼叫 LGSTSQ 記錄錯誤：

WRITE-ERROR-MESSAGE.
    ACCEPT WS-DATE FROM CENTURY-DATE      <-- 手冊 p.190 Format 3
    ACCEPT WS-TIME FROM TIME
    MOVE WS-DATE(1:8) TO EM-DATE
    MOVE WS-TIME(1:6) TO EM-TIME
    CALL 'LGSTSQ' USING BY REFERENCE ERROR-MSG     <-- 手冊 p.217
    MOVE DFHCOMMAREA(1:90) TO CA-DATA
    CALL 'LGSTSQ' USING BY REFERENCE CA-ERROR-MSG
欄位PIC說明
EM-DATEX(8)日期（YYYYMMDD）
EM-TIMEX(6)時間（HHMMSS）
EM-PROG（FILLER）X(9)程式名稱（如 ' LGAPDB01'）
EM-CUSNUMX(10)客戶號碼
EM-POLNUMX(10)保單號碼
EM-SQLREQX(16)SQL 操作描述
EM-SQLRC+9(5)SQLCODE 值
