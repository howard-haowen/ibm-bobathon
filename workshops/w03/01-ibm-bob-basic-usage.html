IBM Bob 入門操作指南

本教材帶領您快速掌握 IBM Bob 的三大核心模式、Skill 安裝與 MCP Server 觀念，並透過實際對話範例，讓您在 10 分鐘內上手 AI 輔助開發。

IBM Bob 是什麼？

IBM Bob 是一個專為企業級軟體工程與維運設計的 Agent-native 開發助手。與通用型聊天 AI 相比，Bob 擁有更強的專案理解力、工具自動化執行能力與更嚴格的架構規範。

Mode 1

Ask 知識模式

專門用來檢索知識、讀懂代碼，或查閱技術文件。適合在新進入一個 Codebase、解讀 COBOL 舊系統或排查日誌錯誤時使用，此模式不會隨意修改您的本地檔案。

Mode 2

Plan 規劃模式

專注於分析複雜需求、架構設計或擬定步驟。在此模式下，Bob 會在不撰寫繁複代碼的前提下，幫助您列出技術規範、分析影響範圍與生成 ADR 文件。

Mode 3

Agent 執行模式

具備完整代碼編輯、命令執行、工具呼叫等高權限功能。當規劃與觀念確定後，切換至此模式可讓 Bob 自動為您修改程式碼、建立檔案與執行本地測試。

快速上手：你的第一個 AI 對話

以一個 COBOL 程式為例，示範如何依序切換三種模式完成一項文件化任務。

01

Ask 模式 — 理解程式用途

切換至 Ask 模式，詢問 Bob 某隻 COBOL 程式的功能，不修改任何檔案。

提示詞範例 
COBOL/LGAPOL01.cbl 這隻程式是做什麼用的？它的主要業務邏輯是什麼？
02

Plan 模式 — 規劃文件產生計畫

切換至 Plan 模式，讓 Bob 擬定文件化的步驟與結構，確認後再動手。

提示詞範例 
請為 COBOL/LGAPOL01.cbl 規劃一份技術文件的產生計畫，說明要涵蓋哪些章節與內容。
03

Agent 模式 — 實作並輸出文件

切換至 Agent 模式，依據計畫讓 Bob 實際產出 HTML 技術文件並寫入本地檔案。

提示詞範例 
請依照剛才的計畫，產出 COBOL/LGAPOL01.cbl 的技術文件並儲存為 output/lgapol01-doc.html。

IBM Bob 核心觀念

在使用 Bob 時，您會經常接觸到三個核心名詞，了解它們能讓您的對話事半功倍：

名詞 核心含意 在工作坊中的實際用途
Mode (模式) 設定 AI 的行為守則與可用工具集。 用 Ask 模式讀懂 COBOL 程式結構；切換至 Plan 模式規劃文件化的章節與範圍；最後用 Agent 模式實際產出 HTML 技術文件。
Skill (技能) 一組可重複使用的特定工作流與專業指導原則。 使用 using-git-worktrees Skill 在安全的隔離分支中進行 COBOL 程式修改，不影響主線；使用 find-skills Skill 尋找更多可協助 COBOL 分析的技能。
MCP Server Model Context Protocol 伺服器，連接外部工具與資料源。 透過已設定的 docs-mcp-server（SSE，port 6280），讓 Bob 即時查詢技術文件，回答相關的問題。

如何安裝與啟動一個 Skill

Bob 的能力是可無限擴展的。本專案目前已安裝下列兩個專案級 Skill，您可以在對話中直接啟用它們：

Skill 名稱 用途說明
find-skills 協助使用者探索並安裝 Agent Skill。當您詢問「有沒有可以做 X 的技能？」時，Bob 會透過此 Skill 搜尋可用的技能生態系，並提供安裝指令。
using-git-worktrees 在執行實作計畫或需要隔離工作區時啟動。引導 Bob 建立獨立的 Git Worktree，確保功能開發不污染目前分支，並自動偵測現有隔離狀態。 
# 使用特定技能的 Prompt 範例

# 啟用 find-skills：尋找適合的技能
有沒有可以幫我做 COBOL 程式碼文件化的技能？

# 啟用 using-git-worktrees：建立隔離工作區
請在開始實作前幫我建立一個獨立的 Git Worktree。

小技巧

在對話框輸入 / 可快速選擇已安裝的技能，例如輸入 /find-skills 直接啟用。

如何設定 MCP

MCP（Model Context Protocol）可讓 Bob 連接外部工具與服務，擴展其原生能力。本專案目前的 MCP 設定（.bob/mcp.json）如下：

目前的 MCP 設定

已連接 docs-mcp-server，透過 SSE 傳輸協定提供本地文件檢索服務：

{
  "mcpServers": {
    "docs-mcp-server": {
      "type": "sse",
      "url": "http://localhost:6280/sse"
    }
  }
}

若您需要新增其他 MCP Server，只需將設定描述給 Bob，它便能協助您完成設定並驗證是否生效。

專業提示 (Pro Tip)

一次只做一件事

在使用 Agent 模式時，建議將複雜的任務拆解成多個小對話。先用 Plan 模式進行架構確認，再用 Agent 模式寫代碼，最後在 Ask 模式下進行程式碼複審，這能保證最高的生成品質。
