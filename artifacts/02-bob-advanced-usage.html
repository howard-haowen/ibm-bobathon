IBM Bob 進階功能設定

學會三種模式之後，本教材帶您認識 Bob 設定畫面裡的三個重要功能：MCP（連接外部資料來源）、模式（切換 Bob 的工作方式）與技能（教 Bob 特定工作的做法）。所有操作都在 Bob 的設定介面完成，不需要寫任何程式。

本頁目錄
  1. MCP — 讓 Bob 連接外部資料來源，例如教育新聞
  2. 模式 — 切換 Bob 的工作方式，也能建立專屬的教學助理
  3. 技能 — 教 Bob 特定工作的做法，並查看已安裝的技能
💡

怎麼打開設定畫面

點選 Bob 面板中的設定圖示（齒輪），會看到不同的分頁。本教材用到其中的 MCP、Modes、Skills 三個分頁。畫面的實際文字與排版可能隨 Bob 版本略有不同，請以你看到的為準；有疑問時，隨時可以直接問 Bob：「我要怎麼查看目前有哪些 MCP？」

MCP：連接外部資料來源

介面位置 設定（齒輪）→ MCP 分頁

MCP（Model Context Protocol）是一套開放標準，讓 Bob 能連上外部的工具與資料來源。沒有 MCP 時，Bob 只能靠自己已知的知識回答；連上之後，Bob 就能在對話中即時取得外部資訊。本專案的備課流程用一個叫 rss-reader 的 MCP，讓 Bob 讀取教育新聞與教學資源的更新（選用 A 素材匯入）。

你想做的事 在 MCP 分頁的操作
查看目前連接了哪些 MCP 打開 MCP 分頁，清單中會列出已設定的 MCP 伺服器。本專案預先設定了 rss-reader（啟用）、workspacemcp 與 excalidraw（停用）。
暫時關閉或重新開啟某一個 MCP 在清單中找到該伺服器，使用它旁邊的開關（電源）切換啟用或停用。
連線出問題時重新啟動 在該伺服器旁點選重新整理（重新啟動）圖示。
只開放其中某幾項功能 展開該伺服器，可以分別開啟或關閉它提供的個別工具。關掉用不到的工具，可以讓 Bob 的回應更精簡。
整個關閉 MCP 功能 取消勾選 Use MCP Servers。關閉後 Bob 無法連接任何 MCP，備課流程中的選用 A 素材匯入也就無法使用。
尋找更多可用的 MCP 在 MCP 分頁開啟 Marketplace，瀏覽並安裝社群提供的 MCP 伺服器。安裝前請先確認它的用途，並留意它是否需要你提供帳號或金鑰。
本專案的 MCP 現況：rss-reader 啟用中，可讀取 Feed 的文章清單，也能取得單篇文章的內容。workspacemcp（連接 Google 日曆、Gmail 等，選用 C 行政整理）與 excalidraw 預設為停用，本流程的主步驟都用不到它們。涉及學生個資的內容，請不要交給任何外部服務處理。

專案根目錄的 teacher-feeds.opml 收錄了 9 個精選 Feeds，分為「教育新聞」（國立教育廣播電臺文教新聞、The Guardian Education、The Hechinger Report、EdSurge）、「科普」（研之有物）與「各科教學資源」（報導者、我們的島、BBC 6 Minute English、TED-Ed）。注意：其中 BBC 6 Minute English 為 Podcast、TED-Ed 為影片連結，不是文字全文；遇到時 Bob 會請你改提供文字稿或其他來源，不會自行編造內容。國文、物理、生物、地球科學、歷史等科目目前沒有專屬 Feed，可自行補充。

情境範例：從指定 Feed 取得文章（Ask 模式）
請從 teacher-feeds.opml 裡的 The Guardian - Education 抓取最新 5 篇文章，列出標題與摘要讓我選一篇，我想拿來當作課堂討論的素材。
預期 Bob 的回應方向（示意）
Bob 讀取 teacher-feeds.opml 找到該 Feed，透過 rss-reader 取得最新文章，以標題與摘要列出，讓你直接在對話中挑選，不需要自己開瀏覽器逐篇找。
情境範例：取得選定文章的全文（Ask 模式）
我選第 2 篇，請幫我取得全文，並記錄標題與來源網址，之後設計啟發提問時會引用。
預期 Bob 的回應方向（示意）
Bob 會先嘗試取得全文；若內容缺失或不完整（例如 Feed 只提供摘要），改用 defuddle 技能從原始網頁萃取正文。引用素材時會標示出處，未取得全文前不會宣稱已閱讀該素材。
💡

小技巧

如果在 MCP 分頁沒有看到 rss-reader，或它顯示連線失敗，可以直接問 Bob：「請幫我檢查 rss-reader 這個 MCP 為什麼沒有連上。」Bob 會告訴你可能的原因與處理方式。

模式：切換 Bob 的工作方式

介面位置 對話框左側的模式選單；設定（齒輪）→ Modes 分頁

模式就像 Bob 的「職務」：同一個 Bob，換一個模式，工作方式和能動的東西就不同。單元一已經用過 Ask、Plan、Agent 三種內建模式；這裡補充怎麼切換，以及怎麼替自己建立專屬的教學助理模式。

內建模式 適合做什麼 備課時的用法
Ask 取得資訊與解釋，不會修改檔案。 釐清主題、了解學生可能的學習難點，或單純想問問題時使用。
Plan 動手之前先規劃與設計。 規劃教學目標、時間流程與要產出的檔案，確認方向後再往下做。
Agent 實際建立與修改檔案，擁有最完整的工具權限。 確認計畫後，由它產出教案、提問、文案與教學網頁。

三種切換方式

方式 說明
下拉選單 點選對話框左側的模式選單，直接挑選想用的模式。
鍵盤快速鍵 macOS 按 ⌘ + .，Windows 或 Linux 按 Ctrl + .。每按一次就依序切換到下一個模式。
Bob 的建議 當 Bob 判斷另一個模式更適合時，會提出切換建議，點選接受即可；任務進行中它也可能依需要自行切換，例如規劃完成後轉到 Agent 模式。

建立專屬的教學助理模式

如果你常做同一類工作，可以建立自己的模式，把「角色」和「注意事項」一次設定好，之後不必每次重新交代。操作步驟如下：

步驟 操作
1 點選設定（齒輪），進入 Modes 分頁。
2 點選新增（+）圖示，建立新模式。
3 填寫欄位：Name（顯示名稱）、Slug（簡短代號）、Save Location（儲存範圍，選專案可讓這個專案共用）、Role Definition（角色定義）、When to Use（何時使用，選填）、Description（說明，選填）、Available Tools（可使用的工具）、Custom Instructions（自訂指示）。
4 點選 Save 儲存，新模式就會出現在模式選單中。
填寫範例：高中教案設計助理（示意，請依自己的需求調整）
Role Definition： 你是一位熟悉高中教學的教學設計顧問，協助教師依學科、年級、時數與學生程度設計教案、活動與啟發提問。 Custom Instructions： 一律使用繁體中文（台灣）。缺少學科、年級、課程主題、單堂分鐘數、學生程度其中任一項時，先向教師詢問，不要自行假設。產生教材前，先查專案內 108 課綱資料夾的對應內容；找不到對應科目就略過，不要自行補課綱。教學目標若由你擬定，須標示為「擬定，請教師確認」。不引用不確定的課綱條文。
這樣設定的效果（示意）
之後只要切換到這個模式，Bob 就會以教學設計顧問的方式回應，並主動確認必填資訊，不必每次重新說明你的偏好。
💡

小技巧

Modes 分頁也有 Marketplace，可以瀏覽並安裝別人整理好的自訂模式。「Available Tools」決定這個模式能做什麼，只想讓它提供建議、不要動到檔案時，可以只開放讀取類的工具。自訂模式不會取代專案中的 AGENTS.md，兩者會一起發揮作用。

技能：教 Bob 特定工作的做法

介面位置 設定（齒輪）→ Skills 分頁

技能是一份可重複使用的工作說明，告訴 Bob 在特定場合應該怎麼做。Bob 會依你的需求和每個技能的說明，自動判斷要不要啟用；同一場對話中，同一個技能只會載入一次。技能可以放在「專案」或「個人（全域）」兩個位置，兩邊有同名技能時，專案內的優先。

你想做的事 操作方式
查看目前有哪些技能 打開 Skills 分頁，可看到目前載入的技能與它們的位置，也能確認專案內或個人目錄的技能是否都有被正確讀取。
決定 Bob 啟用技能前要不要先問你 預設是 Bob 啟用技能前會先徵求你的同意。若想省略，到設定的 Auto-Approve 區塊，開啟 Skills 開關。剛開始使用時建議維持預設，比較清楚 Bob 做了什麼。
尋找新技能 直接問 Bob，例如：「有沒有可以幫我處理 Word 檔的技能？」Bob 會用 find-skills 技能搜尋，並說明來源與安裝量，由你決定要不要安裝。
安裝新技能 請 Bob 依專案規則安裝到本專案。安裝前請先看清楚來源與用途，安裝後回到 Skills 分頁確認它已出現。

本專案目前預先安裝了以下 8 個技能（說明依各技能的說明檔與 AGENTS.md）。另外，專案內的 108 課綱資料夾不是技能，而是 Step 0 查閱的資料：

技能名稱 用途說明
defuddle 網頁正文萃取。選用 A 素材匯入時，Feed 只有摘要、或你直接貼網址，Bob 就用它從網頁取得乾淨的文章全文。
markitdown-cli 文件轉檔與影片逐字稿。選用 A 素材匯入時，把你提供的 PDF、Word、PowerPoint、Excel 檔轉成文字供 Bob 閱讀，也能取得 YouTube 影片的逐字稿（影片沒有字幕時會如實告知）。電腦需另外安裝轉檔軟體，Bob 會先徵求你的同意。含學生個資的檔案請勿提供。
design-taste-frontend 網頁的視覺設計。負責 Step 4 主題式網站（課程官網、活動宣傳頁、遊戲化互動專題）的版面、字體與配色，不用來產生圖片。
svg-logo-designer 選用 E 學習圖表。產出 SVG 圖表幫助學生理解較難的概念。它原本是設計品牌標誌的技能，用於教學圖表時會跳過品牌相關的詢問，成果請老師檢視。
deploy-to-vercel 把網頁發佈到 internet。只在你於本機確認成果、並明確要求發佈時才使用；Bob 會先列出要上傳的檔案給你確認，只上傳網頁相關檔案（不含教案文件），預設為預覽版本。
workspace-cli 選用 C 行政整理。協助操作 Google 日曆、Gmail、雲端硬碟、文件與試算表。需要先完成 Google 帳號授權，且 workspacemcp 預設為停用。涉及學生個資的內容不得透過此流程處理。
agent-browser 瀏覽器自動化。需要操作網頁、截圖或檢查網頁呈現時使用，不是主步驟的必要工具。
find-skills 協助探索並安裝額外的技能（來源 skills.sh）。安裝時 Bob 會遵守專案的安裝規則。
情境範例：請 Bob 說明現有的技能（Ask 模式）
請用淺白的方式列出這個專案目前有哪些技能，各自適合在備課的哪個步驟使用？我是不會寫程式的高中老師。
預期 Bob 的回應方向（示意）
Bob 會依專案內的技能整理出清單，並對照課綱對照、差異化教案設計、啟發提問、摘要與宣傳文案、主題式網站等步驟說明各技能的用途。你也可以同時打開 Skills 分頁，核對 Bob 說的和畫面上看到的是否一致。
💡

小技巧

教案設計、啟發提問、摘要與宣傳文案（Step 1 到 3）沒有專屬技能，由 Bob 依 AGENTS.md 的範本直接生成，所以品質取決於你提供的資訊是否完整。課綱對照（Step 0）讀的是專案內的 108 課綱資料夾（綜合型高級中等學校版本）；找不到你的科目時會直接略過，不需要你補課綱。部分技能需要電腦另外安裝軟體才能完整運作；若 Bob 回報缺少什麼，請照它的說明處理，或請它協助。
