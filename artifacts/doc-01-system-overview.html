第二章：程式結構與組織

2.1 業務功能摘要

GENAPP 實作保險公司後端核心邏輯，分為兩大業務域與支援服務群：

客戶管理（Customer Management）

操作程式說明
新增客戶LGACUS01 → LGACDB01 → LGACVS01含郵遞區號驗證、詐欺檢查、客戶流水號分配
查詢客戶LGICUS01 → LGICDB01 → LGICVS01以客戶號查詢基本資料
更新客戶LGUCUS01 → LGUCDB01 → LGUCVS01更新客戶基本資料

保單管理（Policy Management）— 5 種保單類型

操作程式說明
新增保單LGAPOL01 → LGAPDB01 → LGAPVS01含 COMMAREA 驗證、ODM 業務規則（可選）
查詢保單LGIPOL01 → LGIPDB01 → LGIPVS01支援多筆資料回傳
刪除保單LGDPOL01 → LGDPDB01 → LGDPVS01DB2 DELETE（FK CASCADE）+ VSAM 同步
更新保單LGUPOL01 → LGUPDB01 → LGUPVS01游標鎖定（FOR UPDATE）+ VSAM 同步
