# 課綱對照查詢 (Step 0 參考)

## 資料來源

`108curriculum/` 內有 9 個領域資料夾（`國語文`、`英語文`、`數學`、`社會`、`自然科學`、`科技`、`藝術`、`健康與體育`、`綜合活動`），每個資料夾各有 1 份「綱要」（檔名開頭為「十二年國民基本教育課程綱要」）與 1 份「課程手冊」，皆為 `.md`。另有 [`108curriculum/檔案清單.md`](../../../../108curriculum/檔案清單.md)（來源網址）與 [`108curriculum/轉換紀錄.md`](../../../../108curriculum/轉換紀錄.md)（轉檔限制）。

必須讓教師知道：
- 這批課綱是**「綜合型」高級中等學校**版本（來源：國家教育研究院），教師已同意使用，對照結果以此為準。
- 只有**領域級**檔案，沒有「國文」「物理」「歷史」這類科目級檔案；需先把 `subject` 對應到領域資料夾。
- 檔案由 ODT / PDF 轉成 Markdown，**圖片一律成為 `[Image Placeholder]`、數學公式遺失（`[Formula Not Decoded]` 等）**，合併儲存格表格以重複填入近似。圖與公式不可作為引用依據。

## 定位方式（已實測，勿假設有標題）

多數綱要檔沒有 Markdown 標題（`#`），只有英語文綱要有。用 `grep` 以關鍵字或代碼定位，再只讀相關段落，**不要整檔載入**（綱要最大約 890 行，課程手冊最大約 2,760 行）。

| 領域 | 可用的定位關鍵字（實測） |
| :--- | :--- |
| 數學 | 學習內容代碼 `N-10-`、`A-10-`、`S-10-`、`R-10-`、`D-10-`；「學習單元主題與內容類別」表的「年級」欄。**該表與學習內容代碼目前只有年級 `10`（高一）的 8 個單元**；檔內查無 `11`、`12` 年級的單元，只有「附錄三」提到「十一年級」分流的選修銜接單元。高二、高三的數學主題因此視為查無對應，依跳過規則處理 |
| 國語文 | 學習內容代碼如 `Ab-V-`、`Ac-V-`、`Ba-V-`；「學習表現」「學習內容」段落；「第一學年」等課程表字樣 |
| 英語文 | 有 `#` 標題：`# 伍、學習重點`、`## 一、學習表現`、`## 二、學習內容`、`# 參、時間分配`；代碼如 `1-Ⅴ-1` |
| 社會 | 代碼如 `歷1a-Ⅴ-`、`地1a-Ⅴ-`、`公1a-Ⅴ-`（學習表現）；「學習內容」段落 |
| 自然科學 | 學習內容代碼如 `PEa-V-`（物理）；「學習內容編碼方式說明」；各科段落標記「（一）物理」等 |
| 科技、藝術、健康與體育、綜合活動 | 「學習表現」「學習內容」段落；各檔的「學習重點」說明；課程表的「第一學年」等字樣 |

## 年級對應

只有數學綱要以年級（10、11、12）切分單元；其他領域的學習表現／學習內容以「學習階段Ⅴ（高級中等學校）」標示，**不分高一、高二、高三**，各學年學分配置見各檔課程表。除數學外，學習重點是整個高中階段共用，年級差異在 Step 1 的差異化設計處理，**不得自行推定哪個條目屬於哪個年級**。
