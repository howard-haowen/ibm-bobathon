# 高中教師備課流程 (Lesson Prep)

角色、繁體中文輸出、教師決策優先、不杜撰、隱私等核心原則見根目錄 [`AGENTS.md`](../../../AGENTS.md)，本技能只負責流程。

**順序固定：Step 0 → 1 → 2 → 3 → 4；Step 5 只在教師於本機確認成果後、明確要求時才執行。** 選用 A、B、C、E 依需求啟用。每一步的輸出是下一步的輸入，不可亂序。

## 教師輸入欄位

必填欄位缺少時，用 `ask_followup_question` 詢問，取得後才進入 Step 0 / 1；不得自行假設。

| 欄位 | 必填 | 說明 |
| :--- | :--- | :--- |
| `subject` | 是 | 學科（國文、英文、數學、物理、歷史…） |
| `grade` | 是 | 高一 / 高二 / 高三，或其他 |
| `lesson_topic` | 是 | 課程主題 |
| `duration_minutes` | 是 | 單堂分鐘數與堂數（如 50 分鐘 × 2 堂） |
| `student_level` | 是 | 先備知識、背景、程度（基礎／一般／進階；班級特性） |
| `differentiation_needs` | 否 | 分層、補救、加深加廣、語言或學習支持；未提供時先詢問 |
| `learning_goals` | 否 | 未提供時由你擬定並請教師確認 |
| `class_size` | 否 | 影響分組活動 |
| `resources_available` | 否 | 投影、平板、實驗器材等 |
| `material_url` / 貼上文字 / 本機檔案 | 否 | 選用 A 素材來源（本機檔案支援 PDF、DOCX、PPTX、XLSX） |
| `question_focus` | 否 | 啟發提問偏好（批判思考、跨領域等） |
| `promo_audience`、`promo_tone` | 否 | 宣傳文案對象與語氣；未指定時詢問 |
| `site_type` | 否 | `course-site`／`event-page`／`gamified`；未提供時詢問 |
| `diagram_needs` | 否 | 選用 E：想用圖表說明的概念 |
| `publish` | 否 | 教師本機確認後才會提出 |
| `output_format` | 否 | 預設 `.md` + `.html`；需要 Word 才加 `.docx` |

## 輸出資料夾與檔名

一份教案的所有產出放在**同一資料夾**，檔名不重複學科與年級。

- 根目錄 `output/`（已被 `.gitignore` 排除；不存在時建立）
- `<folder>` = `output/<subject>-<grade>/`；同學科同年級的單元共用
- `<topic>` = `lesson_topic` 轉成的檔名
- slug 規則（`<subject>-<grade>` 與 `<topic>` 皆適用）：
  1. `<subject>` 與 `<grade>` 以 `-` 連接
  2. 中文原樣保留，**不得轉拼音或羅馬化**
  3. 空格、標點、特殊字元（「：」「，」`:` `,`）換成 `-`，合併連續 `-`，去除首尾 `-`
  4. 英文字母轉小寫
  5. 範例：國文、高二、「赤壁賦：情景交融」→ `output/國文-高二/`，檔名基底 `赤壁賦-情景交融`

| 產出 | 路徑（以數學、高一、三角比為例） |
| :--- | :--- |
| 教案主檔 | `output/數學-高一/三角比.md` |
| 主題式網站 | `output/數學-高一/三角比-<site_type>.html`（只有一個網頁也保留後綴） |
| 入口頁 | `output/數學-高一/index.html`（同資料夾有**多個網頁**時才產生） |
| 素材全文（選用 A） | `三角比-material.md` |
| 學習圖表（選用 E） | `三角比-diagram-1.svg`、`-diagram-2.svg`… |
| Word（選用 B） | `三角比.docx` |

同一單元多版本（如不同 `student_level`）時加後綴：`三角比-基礎.md`、`三角比-進階.md`，網頁與圖表依此類推。檔名不含日期，日期放 frontmatter。

## Step 0 — 課綱對照

目標：產生教材前先依 `108curriculum/` 對照課綱。**詳細的科目→領域對照、grep 定位關鍵字、年級限制見 [`references/curriculum-lookup.md`](references/curriculum-lookup.md)，執行前先讀。**

1. 依對照表找領域資料夾；**找不到領域，或領域內找不到對應年級／單元／主題時，直接跳過課綱參考**，不要求教師補課綱要點，並在「課綱對應」欄註明「`108curriculum/` 查無對應，已略過課綱對照」，進入 Step 1。
2. 找得到時，用 `grep` 定位後只讀相關段落（不要整檔載入），擷取學習表現、學習內容（條目與代碼）、建議節數（數學有）、核心素養。
3. 產出「課綱對照摘要」：每條標示**來源檔名與條目代碼**，**逐字引用**，不改寫、不憑記憶補條文。
4. 告知教師這是「綜合型」高級中等學校版本，且圖片與數學公式在轉檔時已遺失，不可作為引用依據；請教師確認摘要後才進入 Step 1。
5. 摘要寫入教案「教學概覽 → 課綱對應」。

## Step 1 — 差異化教案設計

輸入：五個必填欄位、選填欄位、Step 0 的結果。無專屬工具，依 [`references/lesson-template.md`](references/lesson-template.md) 直接生成。

1. 檢查五個必填欄位，缺少者先詢問。
2. 確認 Step 0 已完成（教師確認的摘要，或略過註記）。
3. 依上方規則決定 `<folder>`、`<topic>` 並建立資料夾。
4. 教師未提供 `learning_goals` 時擬定並請教師確認後再繼續；有課綱對照時，目標須能對應到 Step 0 引用的條目，但不更動課綱條目。
5. 依 `duration_minutes` 切分時間流程，**各段時間加總必須等於總時數**；活動須考慮 `student_level`、`class_size`、`resources_available`。
6. 在「時間流程與活動設計」內加入「差異化設計」小節，至少含：分層目標（基礎／一般／進階，或依教師分層）、分層活動或任務、支持策略（鷹架、提示、延伸挑戰）、各層形成性檢核。程度高於或低於課綱年段時以差異化策略處理。
7. 建立 `<folder>/<topic>.md`，寫入 frontmatter 與「教學概覽」「教學目標」「時間流程與活動設計」。教師需要範本沒有的欄位（rubric、小考）時，在該章節之後增補小節，標示「擬定，請教師確認」。

未完成必填欄位、輸出路徑、Step 0、教學目標確認前，不得進入 Step 2。

## Step 2 — 啟發提問

輸入：教案內容、選用 A 的 `material_full_text`（若有）、`question_focus`。

1. 有匯入素材時先「消化整理」：條列重點、關鍵概念、可能爭議或限制，標示出處，再據此設計問題；否則以教案內容為依據。
2. 為每個主要教學段落設計提問，由淺入深：暖身 → 核心 → 延伸與批判。
3. 每題附「設計意圖」「可能的學生回應／追問」「分層提示」（對應 Step 1 的分層）。
4. 有 `question_focus` 時優先採用，否則依 `subject` 與 `student_level` 擬定。
5. 引用素材須標示出處，問題須可由素材或教案支持，不得假設素材沒有的情節。
6. 寫入同一份 `.md` 的「啟發提問」章節。

不得自行更動教學目標或時間流程；若提問顯示教案需調整，先回報教師，同意後回到 Step 1 修訂。

## Step 3 — 摘要與宣傳文案

1. **摘要**：3 到 5 句繁體中文；有素材時另列素材重點摘要（附來源）。
2. **宣傳文案**：依 `promo_audience`、`promo_tone` 撰寫，未指定時詢問；含標題、主文、行動呼籲，可附短版（公告或社群貼文）。
3. 寫入 `.md` 的「摘要」「宣傳文案」。文案不得含學生個資；不產生海報或任何圖像。

進入 Step 4 前，`.md` 必須含六章節：教學概覽、教學目標、時間流程與活動設計、啟發提問、摘要、宣傳文案；缺漏先補齊。

## Step 4 — 主題式網站

| `site_type` | 用途 | 內容重點 |
| :--- | :--- | :--- |
| `course-site` | 課程／單元入口 | 概覽、目標、時間流程（表格或時間軸）、啟發提問（卡片）、摘要、素材與圖表 |
| `event-page` | 活動宣傳 | 以 Step 3 宣傳文案為主：標題、主文、行動呼籲、活動資訊（教師提供）；其餘章節置於下方 |
| `gamified` | 學生問答、配對、闖關練習 | 單檔網頁內互動練習；題目必須來自教案內容 |

1. 確認六章節齊全與 `site_type`（未提供時詢問，可一次要求多種）。
2. 由你直接把 `.md` 各章節寫成 HTML（本專案沒有 Markdown 轉 HTML 的 Skill，也不需教師安裝轉檔工具）。
3. 用 `design-taste-frontend` 技能套用視覺風格（需 Node 22 以上與 Chrome/Edge/Chromium，工作檔寫入 `.taste-skill/`；環境不足時依其 SKILL.md “No Chrome or Node 22” 只做 `lint.mjs` 與人工檢視，並回報檢查器無法執行）。**明確指示：不要產生、抓取或嵌入任何照片或圖片素材**，只用排版、色彩與 SVG（含選用 E 的圖表）。
4. 輸出 `<folder>/<topic>-<site_type>.html`；`gamified` 在同檔加入互動練習。
5. 版面：**精簡**（保留最小必要資訊）、**完整**（`.md` 所有章節都要出現，不得刪減；素材全文置於頁面下方）、**可讀**（適合 A4 列印與行動裝置）。
6. **多個網頁時產生入口頁** `<folder>/index.html`：
   - 標題為教案標題，列出每個網頁的名稱、一句用途與相對路徑連結（如 `href="三角比-course-site.html"`）。
   - 只列網頁，不列 `.md`、`.svg`、`.docx`；視覺風格一致，不用照片。
   - **雙向連結**：`index.html` 連出去的每個網頁，在 `<main>` 第一個元素（標題之前）放「← 回入口頁」連結指向 `index.html`。
   - 新增或刪除網頁時同步更新 `index.html`；新增 `index.html` 時回頭補上既有網頁的連結；只剩一個網頁時移除 `index.html` 與這些連結。
7. 網頁預設只存在本機。請教師先在本機開啟（多頁從 `index.html` 開始）確認，並用白話說明如何開啟與分享。

## Step 5 — 發佈網頁（選擇性）

教師沒有明確要求時，不主動發佈、不詢問發佈以外的雲端動作。**流程見 [`references/publish.md`](references/publish.md)，只在教師本機確認並明確要求發佈後才讀並執行。**

## 選用段落

A（素材匯入）、B（Word 輸出）、C（行政整理）、E（學習圖表 SVG）的細節見 [`references/optional-modules.md`](references/optional-modules.md)，教師需要時才讀。

## 已知限制

- 不支援影音與圖像生成（含海報、插圖、照片）；影音需求只產出腳本、分鏡、旁白稿的文字寫入 `.md`。唯一視覺產出是選用 E 的 SVG。
- Step 1–3 沒有專屬工具，品質取決於教師輸入欄位是否完整。
- 課綱對照只涵蓋 `108curriculum/` 的 9 個領域「綜合型」版本；除數學外不分年級。
- 發佈步驟（`--temporary`、子資料夾部署、單一網頁的根網址行為、含中文資料夾名稱）尚未實測。
- 素材全文不一定可得（Feed 可能只有摘要、Podcast 或影片連結）。
