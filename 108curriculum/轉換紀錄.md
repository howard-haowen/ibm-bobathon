## 工具與版本

| 工具 | 版本 | 用途 | 執行方式 |
|------|------|------|---------|
| docling | 2.148.0 | 手冊 PDF → Markdown | `uvx docling convert --to md <file>` |
| pandoc | 3.10.1 | 綱要 ODT → Markdown | `pandoc <file> -t gfm -o <output>` |

**工具選擇說明**：
- 手冊 PDF：使用者指定 docling。
- 綱要 ODT：嘗試 docling，但 `uvx docling` 預設不含 `odfdo` 套件（需 `pip install 'docling-slim[format-opendocument]'`），執行時拋出 `ImportError`。改用 pandoc（`-t gfm`）成功。

**環境備註**：
- `uv` 位於 `~/.local/bin`，需先 `export PATH="$HOME/.local/bin:$PATH"`。
- 首次執行 docling 已自動下載並快取模型（`docling-layout-heron`、`docling-models`）。

### 綱要 ODT（pandoc）

```bash

```

### 手冊 PDF（docling）

```bash

uvx docling convert --to md "<PDF 檔名>"
```

## HTML → 純 Markdown 後處理

轉換完成後，為讓全部 `.md` 只使用標準 Markdown 語法，對 `108curriculum/*/*.md`（18 個檔案）移除 HTML 標籤（2026-11-06，以 Python 標準函式庫 `html.parser` 與正規表示式處理；處理前先備份至暫存目錄，處理後驗證）。

### 處理規則

| HTML 語法 | 改成的 Markdown 語法 | 處理數量 |
|-----------|---------------------|---------|
| `<table>`（含 `<thead>`、`<tbody>`、`<tr>`、`<th>`、`<td>`、`<p>`、`<ul>/<li>`、`<blockquote>`、`<br>`） | GFM 管線表格（`\| 欄 \| 欄 \|` 加 `\| --- \|` 分隔列） | 128 張表格（ODT 綱要 9 本） |
| `<sup>…</sup>`（議題註記 ¹²³、星號 `*`、`◎`） | Unicode 上標字元（¹²³）；`*` 以 `\*` 表示 | 140 處 |
| `<sub>…</sub>`（H₂O 等） | Unicode 下標字元（₂） | 含於上列 |
| `<em>`、`<strong>` | `*…*`、`**…**` | 表格內 |
| `<span id="anchor-N"></span>`（pandoc 書籤） | 刪除 | 234 處（表格內另有，隨表格重建一併移除） |
| `<section id="footnotes">…<ol><li>…` 與 `<a href="#fn1">` | Markdown 腳註 `[^1]` 與 `[^1]: …`（綜合活動綱要） | 1 組 |
| `<!-- formula-not-decoded -->`（docling HTML 註解） | `[Formula Not Decoded]` | 45 處（數學手冊） |
| 空白標題行 `# `（英語文綱要） | 刪除 | 3 處 |
| 空 blockquote 行 `>`（原書籤殘留） | 刪除 | 23 處 |

### 表格轉換細節

- **多列表頭**：`<thead>` 內有多列時，同一欄各列文字以「／」合併成單一表頭列。
- **rowspan**：被合併的儲存格內容在後續各列重複填入，確保每列自成完整記錄。
- **colspan**：僅第一格保留文字，其餘被合併欄位留空，以維持欄數一致。
- **儲存格內多段落／清單**：多個 `<p>`、`<br>`、`<li>` 以空白連接成一行（`<li>` 加「• 」前綴），因 GFM 表格不允許儲存格內換行。
- 儲存格內的 `|`、`*`、`_` 等特殊字元已加跳脫字元。

### 驗證結果

| 檢查項目 | 結果 |
|---------|------|
| 全部 `*/*.md` 中殘留 HTML 標籤（`<table>`、`<p>`、`<td>`、`<span>`、`<sup>` 等） | 0（僅剩 `<https://…>` 自動連結語法，屬 Markdown） |
| 128 張表格的每列欄數與表頭一致 | 全部一致 |
| 表格前後皆有空白行 | 全部符合 |
| 文字內容 | 僅調整標記；表格以外的敘述文字未改動 |

### 本次處理的限制

- 合併儲存格表格（rowspan/colspan）在 GFM 中無法原樣表達，已用「重複填入／留空」近似；原始版面請參閱 ODT。
- 儲存格內原有的段落換行與清單結構已壓成單行。
- 英語文綱要「時間分配」表有多列表頭樣式的列，因原 ODT 無 `<thead>`，保留在表格本體（第一列作為表頭）。
- `[Formula Not Decoded]` 為 docling 未能解析公式的位置，公式內容仍不保留；請查原始 PDF。
- 本節完成後，下方「轉換結果」「品質抽查」「已知問題彙整」中提到 `<span id="anchor-N">`、空白 `# ` 標題行、退回 HTML `<table>` 的項目，皆為處理前的歷史觀察，現已解決（見「已知問題彙整」備註欄）。
