台灣公開資料
入門指南

AI 專案失敗往往不是模型不好，而是找不到資料。以下三個平台免費、合法，足以支撐大多數 Social Impact MVP。

1. 政府資料開放平台

data.gov.tw ↗

台灣最大 Open Data 入口，由中央政府維護，整合中央部會與地方政府公開資料，支援關鍵字搜尋、下載與 API 呼叫。

教育
  • 全國學校名錄
  • 各級學校學生人數
  • 偏鄉學校資料
醫療與健康
  • 醫院 / 診所名錄
  • 長照機構資料
  • 健康統計
環境永續
  • AQI 空氣品質 / PM2.5
  • 河川監測資料
  • 能源統計
社會福利
  • 社福機構 / 補助資訊
  • 高齡人口統計
  • 長照服務據點

格式：CSV · JSON · XML · REST API

AI 助學 Copilot 社福資源 Agent ESG Dashboard

2. 臺北市資料大平台

data.taipei ↗

台北市政府的 Open Data 平台，專注台北市資料，提供大量即時資料與 API，適合城市應用場景。

交通
  • YouBike 站點 / 即時車位
  • 捷運車站 / 進出站統計
環境
  • 空氣品質監測
  • 降雨 / 溫室氣體統計
城市設施
  • 社會住宅建設進度
  • 醫療院所 / 學校資料
適合專案
  • 智慧交通 Agent
  • 城市導覽 Copilot
  • 高齡友善城市地圖

3. Wikidata

wikidata.org ↗

Wikimedia Foundation 維護的開放知識圖譜。Wikipedia 是給人看的百科，Wikidata 是給 AI 讀取的結構化資料庫。

人物
  • 出生日期、國籍
  • 學歷、職業
  • 關聯組織
組織
  • 成立時間、地點
  • 產業分類、網站
地理資訊
  • GPS 座標
  • 所在縣市、類型
適合專案
  • Knowledge Graph
  • RAG 系統
  • 問答 / 推薦系統
